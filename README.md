# Portfolio website demos

Three demo portfolio websites for students and freshers, made as reusable templates:

- **Minimal Tech** (`minimal-tech/`): clean, minimal, dark mode. For CS / engineering students.
- **Bold Creative** (`bold-creative/`): dark, bold, animated, filterable work gallery. For designers.
- **Classic Resume** (`classic-resume/`): one-page online resume that also prints as a PDF. For MBA / commerce freshers.

Live: https://anurag0224q.github.io/portfolio-demos/

Plain HTML, CSS and JavaScript. No frameworks, no build step, free hosting on GitHub Pages. All text and colours of each site are in its `content.js`. See [CUSTOMIZE.md](CUSTOMIZE.md).

All people in these demos are fictional. Photos are AI-generated; artwork is placeholder.

Made with AI tools as demo portfolio templates.
